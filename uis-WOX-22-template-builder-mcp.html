Template Builder MCP — Conversational AI

Customer says "I need a template for HVAC quarterly service — typical 2 hour visit, journeyman level, includes HIRA + filter check + customer signoff." AI generates the WO Template, the user reviews and saves. Replaces the manual template builder for customers who'd rather describe than configure.

Status: Concept · Deferred Effort: ~5d · 1.34 Extends: WOX-02 · WOX-19 Master ref: #35

1. Where this lives in the app

Page / route: WO Template settings — new template page (path TBD — built per WOX-02 in V1, e.g. /settings/workOrderTemplates/new)
Components touched: WO template editor (from WOX-02), settings layout chrome
New components: <TemplateBuilderChatPanel />, <TemplateBuilderPreview />, <PromptChips /> (path TBD)
API surface: New MCP server appello-template-builder-mcp exposing tools that wrap existing template GraphQL mutations; startTemplateBuilderSession + sendTemplateBuilderMessage resolvers

Adds an AI sidebar to the WO Template settings page. The user describes the work in plain English; the AI calls Appello's own template-building tools (via MCP) to populate line items, attach forms, build a checklist, and set default trade levels. Nothing saves until the user clicks "Save" — the AI is a drafter, not an actor.

Architecturally this is an MCP server, so the same toolkit is reusable from Cursor, Claude Desktop, or any future internal automation. That positions Appello as a "templated work" platform, not just an app — which is exactly the strategic angle Corey flagged.

2. UI Concept

Template settings page split 60/40 — left pane is the populated template form, right pane is the AI chat. The user described the work; AI populated the form and explained what it added. User reviews and saves.

3. Key decisions for Emma + Corey to discuss

D1 Which LLM?
Recommended: GPT-4o mini with strict tool-calling. Cheaper than full GPT-4 (~10× less), fast enough to feel conversational, schema-safe via tool-calling so it can't generate invalid template structures. Promote to GPT-4o full only on retry after schema validation failure.
D2 Prebuilt prompts vs free-form?
Recommended: Free-form input + suggestion chips for common starts ("HVAC quarterly", "Boiler service", "Annual inspection"). Free-form keeps the door open for novel work; chips reduce cold-start friction for first-time users.
D3 Confirmation gate before save?
Recommended: Always — AI never saves without an explicit user click. The left pane shows the populated form so the user reviews before committing. Same trust-building pattern as WOX-19's confirm gate.
D4 Expose the same MCP to other AI tools (Cursor, Claude Desktop)?
Recommended: Yes — that's the strategic upside. Standing up a real MCP server means Corey can wire Appello into Cursor, Claude Desktop, internal Slack bots, or N8N workflows. Turns Appello into a "templated work" platform, not just an app.
D5 Audit AI-generated templates?
Recommended: Yes — tag the row with aiGenerated = true + store the raw prompt + model version on a sibling WorkOrderTemplateAIDraft table. Lets us quality-track what AI generates and roll back if a model upgrade regresses output.
