V1 Priority · must ship in 1.33

10 ITEMS

These are the WO-V1 critical path items. If any of these slips, 1.33 doesn't ship a usable WO product. Every concept here extends an existing WO spec (uis-20a..h) or a foundation spec (LEM-1, Forms).

WOX-01
Dispatch Board V0 — Calendar Toggle "Calendar | Dispatch" toggle on /scheduling. V0 = filtered list. Full Kanban dispatch is V2 (WOX-16).
V1 · 1.33 WOX-02
Work Order Templates — Save & Load Pre-built WO templates ("HVAC quarterly service") that pre-fill subject, forms, line items, trade levels.
V1 · 1.33 WOX-03
Work Order Checklist (V1 minimal) Simple ordered checklist on every WO, drives % complete. Unassigned in V1; assignment is WOX-20.
V1 · 1.33 WOX-04
Equipment ↔ WO Subject Relationship Many-to-many: a WO can reference customer equipment as its subject; equipment shows full WO history.
V1 · 1.33 WOX-05
Generic Time Entry — Placeholder Labor Lines Pre-fill labor on a WO before assigning users ("2 × Journeyman × 4hrs"). Resolves to actual on schedule/check-in.
V1 · 1.33 WOX-06
Forms on WOs — Assigned-Only Visibility Forms attached to a WO show on mobile only for the user assigned to that visit, not the whole crew.
V1 · 1.33 WOX-07
Mobile EDIT Flow — Step-by-Step Reuse Mirror the 5-step CREATE wizard for mobile EDIT so techs don't lose context in a giant form.
V1 · 1.33 WOX-09
Default Forms per WO Template A WO Template carries a default forms list. Creating from template auto-attaches HIRA + signoff + etc.
V1 · 1.33 WOX-10
Trade Level Override on WO Labor Line Per-line trade level override (Foreman covers Journeyman, bills at Journeyman rate). Audited.
V1 · 1.33 WOX-11
WO Pricing Visibility — Financial Permission Gate Hide $ columns on WO detail behind job.financialView for V1. Dedicated permission later (WOX-24).
V1 · 1.33

Post-V1 · 1.34+ candidates

8 ITEMS

Concepts that didn't make the V1 cut but are tracked for 1.34 and beyond. These extend or follow up on the V1 items above. The Dispatch V2 concepts (WOX-16) are particularly important — they show the three industry-leading patterns we're choosing between.

WOX-16
Dispatch Board V2 — 3 Industry Concepts ServiceTitan-style "Tech Day Grid", Jobber-style "Day-Strip Timeline", Housecall Pro-inspired "Map-First Dispatch". Pick one for 1.34.
1.34 WOX-17
SharePoint Phase 2 — In-App iFrame Embed the SharePoint document inside Appello via iframe; OAuth with Microsoft Graph. Edit without context-switching.
1.34 WOX-18
BIM/Revit/IFC 3D Viewer Embedded 3D model viewer (Autodesk Forge) on Project/Job detail. Click an element to spin up a WO with that subject.
1.34+ WOX-19
AI Voice-to-Report (Mobile Field Capture) Tech taps mic, talks for 30s, AI structures it into hours/materials/photos/follow-ups. Confirm gate before save.
1.35+ WOX-20
Checklist User/Role Assignment Extends WOX-03 V1 checklist with per-item user or role assignment. Mobile filters to "Mine" / "Crew" / "All".
1.34 WOX-21
Save WO as Template Action "Save as template…" action on WO detail — strips customer specifics, keeps line items/forms/checklist/trade levels.
1.34 WOX-22
Template Builder MCP — Conversational AI "I need a template for HVAC quarterly service…" → AI builds the template, user reviews & saves. MCP-based tool calls.
1.35+ WOX-23
