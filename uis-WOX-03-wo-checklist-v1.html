Work Order Checklist (V1 minimal)

A simple ordered checklist on every WO — "Arrive on site", "Test gauges", "Replace filter", "Customer signoff". V1 is unassigned (anyone on the WO can check). User/role assignment lives in WOX-20 (deferred). Drives % complete on the WO detail.

Status: Concept Effort: ~3d Extends: WO-3 · uis-20c-create-edit-form Master ref: #19

1. Where this lives in the app

Desktop tab: apps/frontend/src/pages/jobs/[id]/index.tsx (jobType=WORK_ORDER) — new "Checklist" tab in JobTabs alongside Overview / Line Items / Signatures
Mobile screen: mobile WO detail (path TBD — verify, will live under apps/mobile/src/pages/admin/work-orders/[id]/ when shipped)
New components: <WorkOrderChecklistTab />, <ChecklistItemRow />, mobile counterpart
API surface: GraphQL — new WorkOrderChecklistItem model with title · order · photoRequired: Boolean · doneAt: DateTime? · completedByUserId: String?; checkChecklistItem(id, photoAssetId?) mutation

The model is intentionally minimal. Templates seed (per WOX-02) — every WO created from a template gets the template's checklist copied as starting items; users with workOrder.edit can add/remove/reorder on the WO itself. Drag-handle reorder uses the existing order integer pattern from line items.

2. UI Concept

WO detail page with a "Checklist" tab. Progress bar at the top showing completion. Mobile mirror with larger touch targets and a photo-capture affordance for items flagged photo-required.

3. Key decisions for Emma + Corey to discuss

D1 Lives on the WO or on the WO Template?
Recommended: Both. Template carries the canonical list (per WOX-02); each WO gets a copy that is editable per-WO. Edits to the WO checklist do NOT propagate back to the template.
D2 Photo-required per item?
Recommended: Optional photoRequired: Boolean flag. When true, completing the item opens the camera and stores the photo against the item via photoAssetId. Reuses the photo question polish pattern from WO-8 / item #24.
D3 Ordered or unordered?
Recommended: Ordered with drag-handle reorder. order: Int column. Field crews need a sequence ("LOTO before pressure test"). Mobile renders strictly in order; desktop allows drag.
D4 Does completion roll up to a "% done" on the WO?
Recommended: Yes — surfaced on the WO list, the dispatch list (WOX-01), and the WO detail header. Cheap derived value (checked / total). Makes V0 dispatch view far more useful at a glance.
D5 Audit who checked an item even though it's "unassigned"?
Recommended: Yes — always record completedByUserId + doneAt. V1 means "anyone can check"; it does NOT mean "we don't know who checked." Sets up zero-migration assignment in WOX-20.
